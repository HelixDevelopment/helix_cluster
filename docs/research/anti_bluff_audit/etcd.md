# pkg/etcd — Anti-Bluff Audit

- **Test result:** PASS — 4 tests (TestConfigDefaults, TestClientCloseNoPanic, TestMockKV, TestContextTimeout); `go test ./pkg/etcd/... -count=1` → ok, 2.438s.
- **Risk:** HIGH
- **Real-behavior coverage:** Effectively none of the package's claimed functionality is proven. The package (`package.go`) is a wrapper around `go.etcd.io/etcd/client/v3` exposing `New`, `Put`, `PutWithLease`, `Get`, `GetPrefix`, `Delete`, `DeletePrefix`, `Watch`, `Lease`, `RevokeLease`, `KeepAlive`, `Lock`, `Close`, `Raw`. The ONLY production code line any test touches is `Client.Close()` on a nil receiver (the defensive nil-guard at package.go:190). Every real etcd operation — the entire reason this package exists — is completely untested. No test ever connects to etcd, calls `New`, or invokes a single KV/lease/watch/lock method against a real or embedded server.

- **PASS-bluff findings:**
  - `package_test.go:14` `TestConfigDefaults` — Tautological. It constructs a `Config` literal and asserts `cfg.DialTimeout != 0` is false, i.e. that a field it never set is the zero value. This is Go language behavior, not package behavior. The comment "We cannot call New without a real etcd, but we verify the struct" openly admits the default-injection logic in `New` (package.go:26-28, where `DialTimeout == 0` → `5 * time.Second`) is NOT exercised. The actual default-setting feature is unproven; the test would still pass if that logic were deleted. Missing mutation pairing per Constitution 1.1.
  - `package_test.go:22` `TestClientCloseNoPanic` — Only asserts "no panic" on a nil `*Client`. Swallows the return value (`_ = c.Close()`). It proves the nil-guard but never tests `Close()` on a real connected client (the path that actually closes a connection). No sink-side verification that the connection is actually closed.
  - `package_test.go:28` `TestMockKV` — Pure PASS-bluff. `mockKV` is a local 4-line `map[string]string` defined only in the test file; it is NOT used by any production code. The test sets `data["key1"]="value1"` then asserts it equals `"value1"` — asserting a literal it just set into a plain Go map. This tests the Go runtime's map, not pkg/etcd. It exercises a MOCK that has zero connection to the real implementation, exactly the "mock-only validation" pattern banned by CLAUDE-1 rule 5.
  - `package_test.go:36` `TestContextTimeout` — Tests `context.WithTimeout` from the standard library, not pkg/etcd. Asserts `ctx.Err() == context.DeadlineExceeded`. No pkg/etcd symbol is referenced. Filler test.
  - **Whole-package gap:** No integration test against a real etcd (CLAUDE-1 rule 1 / rule 5 require REAL services, not mocks). No round-trip Put→Get proving stored value is retrievable. No GetPrefix multi-key proof. No Delete/DeletePrefix sink-side proof that keys are gone. No Watch test proving an event fires with correct Type/Key/Value (the goroutine + channel + ctx-cancel logic at package.go:103-132 is entirely unverified). No Lease TTL-expiry proof. No Lock mutual-exclusion proof (the distributed-mutex feature at package.go:172-186 — arguably the highest-risk code — has zero coverage). No failure-path coverage: every error-wrapping branch (`fmt.Errorf("etcd ... failed: %w", err)`) is untested. Per CLAUDE-1 rule 2, all four passing tests on this non-functional-from-the-test's-view feature constitute PASS-bluffs.

- **Recommended hardening:**
  - Add an integration test using an embedded etcd server (`go.etcd.io/etcd/server/v3/embed`) or a `testcontainers`/docker-compose etcd, gated behind a build tag or `testing.Short()` skip, per CLAUDE-1 rule 5 (real service, not mock).
  - Round-trip: `New` → `Put(ctx,"k","v")` → `Get(ctx,"k")` asserts `value=="v" && ok==true`; then `Get` of a missing key asserts `ok==false, err==nil` (covers the `len(resp.Kvs)==0` branch at package.go:64).
  - `GetPrefix`: put `a/1`,`a/2`,`b/1`; assert the returned map has exactly the two `a/` keys with correct values.
  - `Delete`/`DeletePrefix`: delete then re-Get and assert the key(s) are gone (sink-side proof).
  - `Watch`: register a watch, `Put` a new value in another goroutine, assert the received `WatchEvent` has `Type=="PUT"`, matching `Key`/`Value`, and `Err==nil`; also assert the channel closes when ctx is cancelled.
  - `Lease`+`PutWithLease`+`RevokeLease`: put a key with a short lease, assert it is gone after `RevokeLease` (or after TTL expiry); `KeepAlive` keeps it alive past the TTL window.
  - `Lock`: acquire the lock in goroutine A, assert a second `Lock` on the same key in goroutine B blocks until A's `unlock()` is called (mutual-exclusion proof) — this is the load-bearing distributed-mutex contract.
  - Mutation-paired `New` default test: with a real/embedded endpoint, call `New(Config{Endpoints: ...})` (DialTimeout unset) and assert via `Raw()` config that the 5s default was applied — so deleting package.go:26-28 makes a test FAIL.
  - Failure-path: point `New` at a dead endpoint with a short DialTimeout and assert operations return the wrapped error (e.g. `errors.Is`/message contains "etcd ... failed"), proving error wrapping is real.
